# 模拟会议 UI 视觉升级（暗色导播台）

日期：2026-11-16 ｜ 模块：`frontend/src/views/meeting`、`frontend/src/views/IndexView.vue`
上游规范：[docs/doc.md](../doc.md) ｜ 需求来源：2026-11-16 用户指定（Awwwards 级视觉升级，纯视觉重做）
相关：[docs/doc-ui.md](../doc-ui.md) §10、[docs/doc-lecture.md](../doc-lecture.md) §7、[docs/doc-conventions.md](../doc-conventions.md) §4

## 1. 问题陈述

模拟会议是核心演示场景，但两页停留在常规后台卡片水平：控制台顶栏最多挤 8 个按钮、共享舞台是纯深色空矩形、名单/聊天是普通白卡、弹窗与提示全是 Element Plus 默认外观、几乎没有状态动效。学生入会只有一个普通弹窗。整体缺少“现场感”和可展示的视觉记忆点。

## 2. 方案概述

- **模块视觉层**：新增 `views/meeting/styles/meeting.css`，定义 `--mt-*` Token、自托管字体、共享原语、环境纹理、局部层级与 reduced-motion。只由两个会议页面引入，不修改全局 `theme.css` / `ui.html`。
- **暗色导播台 + 日光演播室**：跟随全局 `useAppearance`；深色为近黑墨控制室，浅色为暖纸白演播室；共享画面舞台恒为深色（既有规范）。
- **老师控制台**：全幅布局；顶栏只留身份/会议号/状态/在线人数/复制链接/结束会议；演讲、共享、数字人操作收进底部悬浮控制坞；右侧通讯轨；空态/缺凭据/恢复中改为入口屏。
- **学生房间**：全屏入会大厅（海报 + 巨型会议号 + 名字 + 进入）取代普通弹窗；会议中 stage-first + 悬浮顶栏 + 通讯轨 + 移动端切换；结束改为全屏 curtain call。
- **纯视觉重做**：不改后端、接口、路由、LiveKit、store、轮询、凭据与交互路径；仅新增由现有数据推导的展示信息（开讲时长、ON AIR/STANDBY、数字人消息标记）。

## 4. 行为契约（未改变）

- 路由 `/index/meeting?meetid=`、`/meeting/:meetingNo`；host/attendee token 存储键。
- 全部 `/meeting/**` 接口、字段、错误提示；PPT 页建会流程与 `?credential=1`。
- LiveKit 连接、`stageRef.value.videoRef` 的 track attach、隐藏共享音频元素、DataChannel 聊天双写。
- 在线名单只来自 LiveKit 房间事件；降级不报人数、不列台账（ADR-0002）。
- 学生 10s 轮询、刷新恢复、`sendBeacon` 离会、结束后不回填。
- 讲课 `BroadcastChannel` 协议（speak / lesson-start / lesson-stop / lesson-resolve / page / lesson-event）。
- 所有现有按钮、入口、弹窗字段与 `:disabled` 语义。

### 5.3 页面

- `MeetingConsoleView.vue`：全幅；入口屏（空态/缺凭据/恢复中）海报 + 大字 + 本机会议列表；会议中 stage + 通讯轨 + 控制坞 + Attention cue card；数字人弹窗改为 voice booth；所有原 handler 原样保留。
- `MeetingRoomView.vue`：全屏入会大厅；会议中 stage-first + 通讯轨 + 移动端切换；结束全屏 ENDED curtain；join/restore/poll/leave 原样保留。
- `IndexView.vue`：`FULL_BLEED_PATHS` 增加 `/index/meeting`；`meeting.css` 在 ≤820px 对 `.index-layout:has(.meeting-console) .sidebar` 隐藏全局侧栏，保证手机端控制台占满宽度。

### 5.4 动效

- 入口屏（控制台空态/缺凭据/恢复中、学生入会大厅、结束幕）允许一次性 `opacity + 10px` stagger；其余会议界面不做页面入场。
- 会议中的动效全部由状态/操作触发：共享开始/停止、面板切换、新消息、连接变化、结束。
- 环境动效（扫描线、同心环、信号灯脉冲、数字人波形）非阻塞，`prefers-reduced-motion` 下整体关闭。
- 只动 `transform` / `opacity`；hover 不位移；GSAP 未引入，全部 CSS/Vue transition。
