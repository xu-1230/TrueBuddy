# 会议右轨参考 AI 聊天视觉重构（控制台 + 学生会议室）

日期：2026-11-18 ｜ 模块：`frontend/src/views/meeting`
上游规范：[docs/doc.md](../doc.md)、[docs/doc-conventions.md](../doc-conventions.md)、[docs/doc-ui.md](../doc-ui.md)
相关：[docs/doc-lecture.md](../doc-lecture.md)、[views/doctemplate/components/AiChatPanel.vue](../../frontend/src/views/doctemplate/components/AiChatPanel.vue)（视觉参照）

## 1. 问题陈述

会议控制台与学生会议室的右轨（`console-body__side` / `room-body__side`）是「玻璃 mt-rail + 在线成员列表 + 会议聊天」两段式：聊天消息是左侧色条列表、单行输入 + 文字「发送」，与文档模板页的 `AiChatPanel`（实底圆角面板、右侧用户气泡、多行 composer、滚到底按钮）视觉差异明显。用户要求右轨参考 `AiChatPanel` 的 UI 效果整体重构。

## 2. 方案概述

- **整个右轨统一为一块聊天面板**：标题 + 在线成员头像行 + 消息流 + composer；去掉 `mt-rail` 玻璃外壳与上下两段式。
- **两端一起变**：老师控制台 `MeetingConsoleView` 与学生会议室 `MeetingRoomView` 共用新组件 `MeetingChatRail.vue`。
- **视觉采用 AiChatPanel 的 `--tb-*` 实底体系**：实底面板、圆角、用户右气泡、他人左头像 + 浅气泡、多行 composer、圆形发送、滚到底按钮；不再使用 `--mt-*` 字体/材质。
- **在线成员**：头部保留「在线 N」；下方头像行最多 6 个 + 「+N」，点击弹出完整名单浮层。
- **连续消息合并**：同一发送者连续发言（间隔 ≤5 分钟）合并为一组，组首显示头像/姓名/角色/时间。
- **只改前端视觉与分组**：不改会议消息协议、store、发送/轮询逻辑、后端接口。

## 3. 口径

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 范围 | 整个右轨；老师控制台与学生会议室一起改 |
| D2 | 视觉 | AiChatPanel 的实底圆角面板 + `--tb-*`；移除 `mt-rail` 玻璃 |
| D3 | 顶部 | 极简标题「会议聊天」+「在线 N / 已结束」；头像行 + 浮层名单 |
| D4 | 消息 | 自己右中性气泡 + 「我」；他人左头像 + 姓名 + 角色 pill + 浅气泡；数字人魔法图标 + 局部青色 |
| D5 | 分组 | 同一发送者连续消息合并；组首显示头像/姓名/角色/时间，时间窗 5 分钟 |
| D6 | 输入区 | 多行自增高 textarea + 圆形发送 + 快捷键提示；Enter 发送、Shift+Enter 换行；500 字上限 |
| D7 | 加载 / 空态 / 滚动 | 三行圆角骨架；空态「还没有消息，发一条试试」；新增滚到底按钮 |
| D8 | 宽度 / 窄屏 | 保持 `clamp(320px, 24vw, 380px)` 与 ≤1024px「画面 / 聊天」切换 |
| D9 | 字体 | 全部 `--tb-*`；时间 tabular-nums；角色标签小号 pill |
| D10 | 降级 / 结束 | `degraded` 头像行显示「实时连接不可用」并隐藏在线数；`ended` 显示「已结束」并禁用 composer |

### 3.1 默认口径

- 头像行最多 6 个；老师头像用 `--tb-warning` 描边；「+N」打开 `el-popover` 名单（姓名 / 角色 / 在线点）。
- 数字人强调色用局部 `--chat-digital`（复刻原 mt-signal 的 `#087480` / `#7ef0ff`），不引入 `meeting.css`。
- 消息发送者键：自己 → `self`；有 `attendeeId` → `attendee:<id>`；老师 / 数字人等无 attendeeId 的 → `role:kind:nickname`。
- 时间缺失时不做时间窗拆分，只按发送者连续合并。
- 组装顺序按消息列表原顺序，不重排、不补日期分隔。
- 发送成功后清空草稿并保持输入高度；不新增已读/正在输入状态。

## 4. 验收项

| # | 场景 | 预期 |
| --- | --- | --- |
| AC1 | 打开老师控制台 / 学生会议室 | 右轨是一块实底圆角面板，不再是 mt-rail 玻璃 + 两段式 |
| AC2 | 头部 | 「会议聊天」+「在线 N」；已结束显示「已结束」 |
| AC3 | 头像行 | 最多 6 个头像 + 「+N」；点击弹出完整名单 |
| AC4 | 自己发消息 | 右侧中性气泡 + 「我」+ 时间 |
| AC5 | 学生 / 老师发言 | 左侧头像 + 姓名 + 角色 pill + 浅气泡；老师标签为 amber |
| AC6 | 数字人发言 | 魔法图标 + 「数字人」青色 pill + 轻色气泡 |
| AC7 | 同一人连续发言 | 合并为一组，只有组首显示头像/姓名/角色/时间 |
| AC8 | 间隔 >5 分钟的同人发言 | 新起一组 |
| AC9 | 加载 | 三行圆角骨架 |
| AC10 | 向上滚动后新消息到达 | 不强制滚底，出现「回到最新消息」按钮 |
| AC11 | 输入 | 多行自增高；Enter 发送；Shift+Enter 换行；500 字上限 |
| AC12 | 会议结束 | 头部「已结束」；输入与发送禁用 |
| AC13 | 实时连接降级 | 头像行显示「实时连接不可用」，不显示在线数 |
| AC14 | ≤1024px | 保留「画面 / 聊天」切换，右轨占满面板区 |
| AC15 | 降级/结束/加载 | 现有发送、轮询、结束逻辑不变 |

## 6. 明确不做

- 不改会议消息发送、落库、轮询、SSE / DataChannel 协议。
- 不做已读、正在输入、撤回、引用回复。
- 不把 AI chat 的选区、版本、流式阶段搬进会议聊天。
- 不改会议顶栏、控制坞、画面区、结束幕与移动端 switcher 的结构。
- 不写 ADR（可逆的视觉重构）。
