# 2026-11-17 作业批改成绩卡视觉重构

## 1. 范围

重做作业批改页右侧卡堆中的成绩卡（`frontend/src/views/homework/components/ScoreCard.vue`）的版式与视觉层：

1. 从「左右两个盒子拼信息」改为一张**成绩单（EXAM REPORT）**：卡头文件/翻阅、抬头学生与得分刻度、材料清单、扣分账、AI 评语、页脚批改要求；
2. 得分成为唯一主视觉：超大衬线分数 + 档位印章 + 横贯整卡的评分刻度；
3. 按卡片自身宽高做容器自适应，卡堆缩放、页面响应式都不再另写视口断点；
4. 入场动效：分数滚动、印章压印、刻度填充与分区段淡入；`prefers-reduced-motion` 下全部关闭。

本轮**不改**：数据契约、`toRecordFromGrading` 的字段映射、卡堆几何（旋转/缩放/翻阅）、上传与批改链路、后端接口与表结构。

## 2. 已确认口径

- **一张纸，不是一叠盒子**：分组只用细线、留白和小号等宽标签，不做卡片套卡片；材料与扣分两栏之间只有一条竖线。
- **得分色由档位统一派生**：沿用 `scoreTone()` 的 `excellent / good / pass / weak / pending`，通过 `--tone` 一次注入，分数、印章、刻度、页签、分组序号、评语竖线全部跟随；不新增主题 Token，不写原始色值。
- **数据仍只读 `record`**：`files` / `readFiles` / `deductions` 继续在模板里以 `?? []` 兜底；字段契约由 `tests/homework-card-fields.test.js` 锁定。
- **未评分也是完整状态**：分数显示破折号、印章为虚线「待批改」、隐藏刻度；0 分是合法分数，与未评分区分。
- **材料路径只出现一次**：同一组文件的公共目录显示在「01 材料清单」标题下，清单行只留文件名；目录不同时逐行回退显示。
- 扣分统一按扣分语义显示为 `−N`（接口正值/负值都不改变含义），逐项依据保留。
- 卡片在窄宽度（≤460px）改为整张纸滚动，卡头吸顶；其它宽度保持「卡头/抬头固定，材料与评语各自滚动」。

## 3. 版式与尺寸

| 区段 | 内容 | 尺寸口径 |
| --- | --- | --- |
| 卡头 | 2px 得分色顶缘、`GRADE REPORT`、工作流、文件名、上一份/下一份 | 高 44–58px（按 `cqw` 夹紧） |
| 抬头 | `STUDENT` + 学生名 + 份数/大小 + 模型/知识库；`SCORE` + 超大分数 + `/100` + 档位印章 | 双列，`align-items: end`；分数 `clamp(4rem, 15.2cqw, 8.5rem)` |
| 刻度 | 0–100 细轨、60/90 阈值刻线、得分光点、`0 / 60 及格 / 100` | 横贯整卡，`scaleX(--ratio)` 填充 |
| 正文 | 左：材料清单（提交 / 已读）；右：扣分明细 + AI 评语 | 约 `0.82fr / 1.34fr`，中间一条竖线 |
| 页脚 | `REQUIREMENT` + 批改要求（两行截断）+ 品牌末标 | 11px 左右，上缘虚线 |

- 所有字号用 `clamp()` + `cqw`，容器窄时收敛、宽时不无限放大；行高与字距沿用 Ink 的衬线/等宽分工。
- 纸张颗粒以伪元素叠加极低透明度噪点（`--tb-noise`），不使用图片资源。

## 4. 自适应与动效

- 卡片本身设 `container-type: size`，内部按 `@container sheet (...)` 响应：
  - `max-width: 480px` 且 `min-height: 540px`：抬头与正文改单列，正文整体滚动；
  - `max-height: 620px`：压缩抬头与分数；`max-height: 500px`：隐藏页脚与刻度文字、收紧正文；
  - `max-width: 460px`：整张纸滚动、卡头吸顶、隐藏文件名/工作流与页脚末标。
- 正文滚到底部用 `mask-image` 做 18px 渐隐，提示还有内容可读。
- 动效只动 `transform / opacity`：分区段淡入上移、分数滚动（900ms，JS 计数）、印章压印、刻度填充与光点出现；页面卡堆的翻阅动画不变。
