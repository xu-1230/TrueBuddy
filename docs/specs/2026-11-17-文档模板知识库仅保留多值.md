# 文档模板知识库仅保留多值 spaceIds（移除单值兼容）

日期：2026-11-17 ｜ 模块：`backend/tb-module-doctemplate`、`backend/sql`
上游规范：[docs/doc.md](../doc.md)、[docs/doc-conventions.md](../doc-conventions.md)
前序：[specs/2026-11-17-文档模板知识库多选.md](./2026-11-17-文档模板知识库多选.md)
决策依据：[adr/0008](../adr/0008-文档模板知识库仅保留多值-spaceIds.md)

## 1. 问题陈述

多选首版保留了单值 `spaceId` 兼容回退与 `doc_template_generation.space_id` 列。用户要求全链路只保留 `List<String> spaceIds`，不保留单值。

## 2. 口径

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 请求 | `GenerateReqVO` 只保留 `List<String> spaceIds`；删除 `spaceId` 与回退逻辑 |
| D2 | 旧请求 | 携带 `spaceId` 的旧请求被 Jackson 忽略，不报错、不启用检索 |
| D3 | 存储 | 只保留 `doc_template_generation.space_ids`；回填存量后删除 `space_id` 列与索引 |
| D4 | 历史 | 只读 `space_ids`；删除单值回退 |
| D5 | 迁移 | 直接对 PostgreSQL 执行：补列 → 回填 → 删索引 → 删列；仓库不保留迁移脚本 |
| D6 | 文档 | 本 spec + ADR 0008 + 回写 doc-doctemplate / doc-api / doc-database |

## 3. 验收项

| # | 场景 | 预期 |
| --- | --- | --- |
| AC1 | 新前端生成 | 只用 `spaceIds` 工作 |
| AC2 | 旧请求只带 `spaceId` | 不报错；检索增强为空 |
| AC3 | 存量记录 | 迁移后 `space_ids` 回填；历史仍显示原知识库名 |
| AC4 | 数据库最终结构 | `doc_template_generation` 无 `space_id` 列、无对应索引，只有 `space_ids` |
| AC5 | 新后端写入 | INSERT 只引用 `space_ids` |
| AC6 | 存量数据 | 原 `space_id` 非空的行已回填到 `space_ids` |

## 4. 影响面

| 文件 | 变更 |
| --- | --- |
| `backend/.../model/vo/GenerateReqVO.java` | 删除 `spaceId` |
| `backend/.../model/DocTemplateGenerationDO.java` | 删除 `spaceId` |
| `backend/.../mapper/DocTemplateGenerationMapper.java` | INSERT 去掉 `space_id` |
| `backend/.../service/Impl/DocTemplateServiceImpl.java` | 删除回退与单值解析、历史只读 `space_ids` |
| `backend/sql/doc_template.sql` | 建表去掉 `space_id` 与索引 |
| PostgreSQL `tb.doc_template_generation` | 已直接执行补列 → 回填 → 删索引 → 删列；仓库不保留迁移脚本 |
| `docs/doc-doctemplate.md` / `doc-api.md` / `doc-database.md` | 删除单值说明 |

## 5. 明确不做

- 不对旧 `spaceId` 做显式 400 拒绝。
- 不保留 `space_id` 作为 first-id 冗余列。
- 不改前端（已只发 `spaceIds`）。
