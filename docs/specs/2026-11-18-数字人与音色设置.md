# 数字人与音色设置（PPT 页设置弹窗）实施规格

日期：2026-11-18 ｜ 模块：`frontend/src/views/ppt`、`backend/tb-module-lecture`
上游规范：[docs/doc.md](../doc.md)、[docs/doc-conventions.md](../doc-conventions.md)
相关：[docs/doc-lecture.md](../doc-lecture.md)、[docs/doc-database.md](../doc-database.md)、[docs/doc-api.md](../doc-api.md)

## 1. 问题陈述

`/index/ppt` 右侧数字人面板底部原有一个 `avatar-switch` 胶囊按钮，点击按登记表顺序轮换形象，入口语义弱、无法选择具体形象，也无法选择或复刻播报音色。本轮把它改为页面顶栏右上角的「设置」入口：点击打开「数字人与声音设置」弹窗，两个 Tab 分别完成数字人选择与声音选择（内置音色 + 复刻音色）。选择按登录用户持久化到服务端；形象与音色都来自新增的 SQL 表。

## 2. 方案概述

- **入口**：删除 `.avatar-switch`；顶栏最右侧新增齿轮按钮，tooltip「数字人与声音设置」。放映态不提供入口。
- **弹窗**：Element Plus `el-dialog` + 两个 `el-tab-pane`；数字人页为 3 列图片卡片，声音页为搜索 + 性别分段 + 分类筛选 + 行列表；右上角「复刻音色」打开二级弹窗。
- **开启形象预览不加载 Live2D**：为 9 个模型离线生成截图，卡片只加载图片；右侧主面板仍是唯一的 Live2D 运行实例。
- **选择按用户持久化**：新增 `lecture_avatar_preference`，保存当前 `avatar_model_code` 与 `voice_code`；页面挂载时先读偏好再初始化 Live2D。
- **数据表**：`avatar_model`（目录）、`avatar_voice`（内置 + 复刻）、`lecture_avatar_preference`（用户偏好）。
- **音色进入播报链路**：`/ppt/speech/speak` 请求新增 `voiceCode`；后端解析并校验后传给 CosyVoice；不可用时回退默认音色并在 SSE 状态里标记。
- **鉴权**：`/ppt/speech/speak` 保留白名单；其余 `/ppt/**` 移出白名单，要求登录。
- **不做**：不改管理端 `AvatarConfigView`（仍为演示页）；不做 Live2D 卡片内实时预览；不做语音录制。

## 3. 口径

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 入口位置 | 页面顶栏最右侧齿轮按钮；放映态不可用 |
| D2 | 弹窗形态 | 两个 Tab；数字人图片卡片网格；声音搜索/筛选/列表；底部取消 + 保存并应用 |
| D3 | 生效方式 | 先选后保存；保存时先加载形象，成功后才写偏好 |
| D4 | 形象数据 | `avatar_model` 只做目录（编码/名称/类型/缩略图/排序/启停）；模型地址与取景仍在前端 `configs/avatar.js` |
| D5 | 形象缩略图 | Chrome headless 离线截图，输出 `public/live2d/previews/{modelCode}.png` |
| D6 | 音色数据 | 以用户提供的 38 条为蓝本，删除「测试」复刻行；按仓库规范补审计列、`source`、`tts_model`、样本字段 |
| D7 | 音色试听 | 内置音色用阿里云官方 cosyvoice-v3-flash 示例音频；复刻音色播上传样本/粘贴 URL |
| D8 | 复刻输入 | 粘贴公网 URL；上传文件仅在配置了公网可达存储时启用 |
| D9 | 复刻归属 | 仅创建者可见、可删；删除软删并尽力删除云端音色 |
| D10 | 偏好 | 服务端按登录用户保存；表 `lecture_avatar_preference` |
| D11 | 语音失效 | 播报回退全局默认音色，SSE `status started` 带 `voiceFallback`，前端提示 |
| D12 | 鉴权 | 仅 `/ppt/speech/speak` 公开；其余 `/ppt/**` 要求登录 |

## 4. 数据表

### 4.1 `avatar_model`

`id`、`model_code`（唯一）、`name`、`kind`（deepseek/sample）、`preview_image`、`sort`、`enabled`、`create_time`、`update_time`、`creator`、`updater`、`deleted`。

### 4.2 `avatar_voice`

`id`、`voice_code`（唯一）、`name`、`trait`、`age`、`language`、`category`、`gender`、`source`（1 内置 / 2 复刻）、`tts_model`、`audio_preview_url`、`sample_file_id`、`sample_audio_url`、`create_time`、`update_time`、`creator`、`updater`、`deleted`。

### 4.3 `lecture_avatar_preference`

`id`、`creator`（未删除记录内唯一）、`avatar_model_code`、`voice_code`、`create_time`、`update_time`、`updater`、`deleted`。

## 5. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ppt/avatar/list` | 启用中的形象目录，按 `sort,id` |
| GET | `/ppt/voice/list` | 内置音色 + 当前用户复刻音色；附 `defaultVoiceCode`、`cloneEnabled`、`uploadEnabled` |
| GET / PUT | `/ppt/preference` | 读取 / 保存当前用户的形象与音色编码 |
| POST | `/ppt/voice/clone` | multipart：`name`、`gender` 必填，`trait`/`language` 选填，`sourceType=upload|url`，`file` 或 `url` |
| DELETE | `/ppt/voice/{id}` | 仅删除自己的复刻音色；软删 + 尽力删云端 |
| POST | `/ppt/speech/speak` | 请求新增 `voiceCode`；`status started` 新增 `voiceCode`、`voiceFallback` |

## 6. 验收

1. SQL 在 `tb` 库执行成功：3 张表存在；`avatar_model` 9 条；`avatar_voice` 37 条内置音色且均有试听地址。
2. 顶栏齿轮打开弹窗；数字人 Tab 显示 9 张图片卡片；保存后右侧 Live2D 切换，刷新后保持。
3. 声音 Tab 可搜索/筛选/试听；选择内置音色保存后，「试听本页」与讲课播报使用该音色。
4. 复刻音色：粘贴公网音频 URL 可创建；列表仅创建者可见；删除后列表消失、偏好回退。
5. 音色失效时播报回退默认并提示，不中断讲课。
6. `/ppt/speech/optimize`、`/ppt/voice/list` 未登录返回 401；`/ppt/speech/speak` 仍可公开调用。
7. 后端单测、前端 lint/test/build 通过；真接口验证使用临时测试账号。

## 7. 风险

- 9 张截图依赖 Chrome headless 的 WebGL；失败时用占位图并标注。
- 本机 MinIO 为 `localhost`，上传复刻需配置 `tb.lecture.digital-human.public-base-url`；未配置时 UI 禁用上传，仅保留 URL 复刻。
- 上传模式要求公网存储允许匿名读取。
