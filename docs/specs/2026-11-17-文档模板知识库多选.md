# 文档模板生成：知识库选择改为多选（对齐作业批改）

日期：2026-11-17 ｜ 模块：`frontend/src/views/doctemplate`、`backend/tb-module-doctemplate`、`backend/tb-module-knowledgebase`
上游规范：[docs/doc.md](../doc.md)、[docs/doc-conventions.md](../doc-conventions.md)
相关：[docs/doc-doctemplate.md](../doc-doctemplate.md)、[docs/doc-knowledgebase.md](../doc-knowledgebase.md)、[docs/doc-api.md](../doc-api.md)、[docs/doc-database.md](../doc-database.md)、[docs/doc-homework.md](../doc-homework.md)（多选参照）

## 1. 问题陈述

文档模板生成页的知识库选择是单选框：一次只能选一个空间，且请求体只带 `spaceId`。作业批改页早已支持多选（`el-select multiple` + 默认知识库 + `spaceIds` 数组），两页在同一套侧栏里交互不一致；用户也无法让检索增强同时覆盖多个知识库。

## 2. 方案概述

- **前端**：知识库选择改为与作业批改完全同形的 `el-select multiple`（`collapse-tags` / `collapse-tags-tooltip`），选项卡片按 `includes` 打勾；提交时过滤掉「默认知识库」哨兵，只发真实空间 id 数组。
- **后端请求**：`GenerateReqVO` 新增 `List<String> spaceIds`；旧 `spaceId` 保留为兼容回退（新前端不再使用）。
- **检索增强**：知识库 Service 新增 `searchBySpaces(List<Long>, query, topK)`，用一条 pgvector `spaceId in ['1','2']` 查询在选中空间上统一取 topK，不再逐空间拼接。
- **归属收口**：生成前把选中的空间 id 过滤为「当前用户自己的空间」，非本人 id 丢弃并记 WARN——修掉「知道他人空间 id 即可检索其私有内容」的既有缝隙。
- **历史展示**：`doc_template_generation` 新增 `space_ids`（逗号分隔）；历史记录 `kb` 字段展示全部空间名（`、` 连接），存量记录回退到 `space_id`。
- **只改必要面**：不改作业批改页、不改检索链路的其它参数、不改生成主流程。

## 3. 口径

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 请求形状 | 新前端提交 `spaceIds: string[]`；`spaceId` 仅作旧客户端回退，两者都空 = 不启用检索 |
| D2 | 默认知识库 | 前端 `DEFAULT_KB.id = "default"` 只是哨兵；提交前过滤，后端同样忽略 `"default"` |
| D3 | 去重与顺序 | 后端按请求顺序去重；非法 id 记 WARN 后丢弃 |
| D4 | 归属 | 只接受当前用户 `getSpaceList` 返回的空间；非本人 / 已删除 id 丢弃 |
| D5 | 检索 | 单次 `spaceId in [...]` 查询，`topK` 为总条数（默认 5） |
| D6 | 落库 | `space_id` = 第一个有效 id（兼容旧列与索引）；`space_ids` = 逗号分隔的完整列表 |
| D7 | 历史 | 有 `space_ids` 用全部名称；否则回退 `space_id`；都空 → 「默认知识库」 |
| D8 | UI | 与作业批改一致：`multiple`、`collapse-tags`、`collapse-tags-tooltip`、选项 tile/勾选/默认标签不变 |
| D9 | 空选择 | 不启用检索，与旧「默认知识库」等价 |
| D10 | 文档 | 本 spec + 回写 `doc-doctemplate`、`doc-api`、`doc-database`、`doc-knowledgebase`、`doc-conventions` 测试计数 |

## 4. 验收项

| # | 场景 | 预期 |
| --- | --- | --- |
| AC1 | 打开生成页 | 知识库为多选；默认仅选中「默认知识库」 |
| AC2 | 选两个知识库并生成 | 请求体 `spaceIds` 为两个真实 id；不包含 `"default"` |
| AC3 | 检索增强 | 上下文来自两个空间；片段编号连续 |
| AC4 | 只选默认知识库 / 清空 | `spaceIds` 为空；不启用检索 |
| AC5 | 历史记录 | `kb` 显示「空间A、空间B」；旧记录仍显示原单个空间 |
| AC6 | 传入他人私有空间 id | 该 id 被丢弃；不在检索结果中出现 |
| AC7 | 旧客户端只传 `spaceId` | 仍按单空间检索 |
| AC8 | 下拉交互 | 选项勾选 / 取消、折叠标签、清空与作业批改页一致 |
| AC9 | 生成成功提示 | 文案列出全部选中知识库名称 |

## 6. 明确不做

- 不做「公有知识库」选择（生成页仍只列自己的空间）。
- 不做每个空间各自 topK 后再融合（单次 IN 查询取总 topK）。
- 不改作业批改页、不改流程执行链路。
- 不做历史记录的旧数据回填（`space_ids` 为空时回退 `space_id`）。
