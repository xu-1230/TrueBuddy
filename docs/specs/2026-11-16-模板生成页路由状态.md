# 模板生成页路由状态（URL 作为页面状态唯一真相源）

日期：2026-11-16 ｜ 模块：`frontend/src/views/doctemplate`、`frontend/src/router`、`frontend/src/views/IndexView.vue`
上游规范：[docs/doc.md](../doc.md) ｜ 需求来源：2026-11-16 拷问式对齐（grill-me，共识已逐条确认）
相关：[docs/doc-conventions.md](../doc-conventions.md) §5、[docs/doc-doctemplate.md](../doc-doctemplate.md)、[docs/doc-api.md](../doc-api.md)

## 1. 问题陈述

模板生成页（`/index/doc-template`）当前把「哪次生成」「正在看哪份文件」全部放在组件内存里：点历史记录只改本地 `resultDocs` / `activeHistoryId`，点结果卡只改本地 `viewing` / `activeDoc`。导致：

- 刷新、分享、浏览器前进/后退都无法还原当前画面；
- 刚生成的结果与从历史载入的结果无法用地址区分，也无法深链接；
- 页面状态与地址栏脱节，用户无法通过 URL 定位「某次生成的某份文档」。

## 2. 方案概述

- **URL 契约**：`/index/doc-template/:generationId?file=<docId>`。`generationId` 为历史条目 id（= 后端 `generationId`）；`file` 为 `DocFileVO.id`（`doc_template_file` 主键，不是 `infra_file.id`）。
- **状态模型**：URL 为唯一真相源。页面用 `watch([id, file], immediate)` 驱动载入；用户动作只负责 `router.push` / `router.replace`。
- **历史与生成的统一**：生成成功即 `replace` 到 `/:generationId`；历史条目点击即 `push` 到 `/:generationId`；打开文件即 `push` 到 `?file=`。刷新后同一 URL 得到同一画面。
- **只改前端**：不扩展详情接口，不改后端鉴权与查询过滤。

## 3. 口径（已确认）

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 文件标识 | `doc_template_file.id`（`DocFileVO.id`） |
| D2 | 参数形状 | 单数 `file`，无末尾斜杠；`/index/doc-template/:id/?files=` 仅作为可匹配输入，不再生成 |
| D3 | 路由声明 | 单条 `path: "doc-template/:id?"`，`name` 仍为 `doc-template`；非法 id 由页面校验后回退 |
| D4 | 生成后 | 有文档成功 → `replace` `/:generationId`；失败 / 0 份 → 只 toast，不动 URL 与当前结果 |
| D5 | 导航历史 | 历史条目、打开文件、返回列表均 `push`；后退逐步撤销视图切换 |
| D6 | 载入中 | 结果区独立文案「正在载入生成记录…」，不复用生成中状态 |
| D7 | 确定性失败 | id 非法 / 业务码 `1004000005` → toast + `replace` 回基础页 |
| D8 | 暂时性失败 | 网络错误 / 5xx → 保留 URL，结果区「载入失败 + 重新载入」 |
| D9 | 生成中记录 | `status=0` 深链接显示静态提示，不轮询 |
| D10 | `?file=` 失效 | 文档不存在或不属于该次生成 → `replace` 掉 query + toast |
| D11 | 失败 / 0 份记录 | 照常进 `/:id`，结果区显示失败原因或「该次生成没有产出文档」 |
| D12 | badge | 有 id 统一为「生成记录 · …」；无 id 显示模板名 / 未选择模板。不再区分历史 / 本次生成 |
| D13 | 侧边栏 | `isActive` 改前缀匹配；点菜单回 `/index/doc-template` |
| D14 | 测试 | 抽纯函数（URL 解析 / 拼接、侧栏匹配）+ `node --test` |
| D15 | 文档 | 本 spec + 回写 `doc-conventions.md` §5.2、`doc-doctemplate.md` §5/§6；不写 ADR |
| D16 | 越权 | 历史 / 详情未按 `creator` 过滤的问题本次不处理，在 `doc-doctemplate.md` §6 标注「待整改」 |

### 3.1 默认口径

- `?file=` 存在但无 id → 视为畸形，静默 `replace` 回基础页。
- 构建规范 URL 时丢弃 `file` 以外的 query。
- 模板 / 知识库 / 描述等表单输入不进 URL；页内导航保留，刷新清空。
- 历史抽屉开合状态不进 URL；深链接时抽屉默认关闭。
- 同 URL 重复 push 做前置比较，避免 redundant navigation。
- 深链接记录的标题不展示（详情接口无该字段）；抽屉仍只拉 20 条，当前记录不在列表内时不高亮。
- 重复的 `?file=1&file=2` 取第一个值（不会由本页生成）。

## 4. 验收项

| # | 场景 | 预期 |
| --- | --- | --- |
| AC1 | 基础页生成成功 | URL 变为 `/index/doc-template/:id`；刷新仍显示该次结果 |
| AC2 | 点结果卡 | URL 追加 `?file=<docId>`；刷新直接进入查看模式并打开同一份 |
| AC3 | 查看模式按后退 | 回到结果列表；再后退回到基础页，表单内容仍在 |
| AC4 | 点历史条目 | 抽屉立即关闭；结果区显示载入中，随后渲染该次结果 |
| AC5 | 点失败 / 0 份历史条目 | 进入 `/:id`，结果区显示失败原因或空态 |
| AC6 | 手输 `/index/doc-template/abc`、`/999999` | toast + 回基础页 |
| AC7 | 断网刷新 `/:id` | URL 保留；显示「重新载入」，恢复后可重试成功 |
| AC8 | `?file=` 指向不存在 / 不属于该次的文档 | query 被移除并提示，回到结果列表 |
| AC9 | `status=0` 记录深链接 | 静态「生成中」提示，无轮询 |
| AC10 | 在 `/:id` 下侧边栏 | 「文档模板生成」保持高亮；点该菜单回基础页 |
| AC11 | 已载入旧记录时生成失败 | 旧结果与 URL 不变，仅 toast |

## 6. 明确不做

- 不改后端接口、VO、鉴权白名单、`creator` 过滤。
- 不引入 `@vue/test-utils` / jsdom 组件测试栈。
- 不把表单输入、历史抽屉开合、元素选择模式写入 URL。
- 不实现生成中自动轮询、失败记录自动重试。
- 不写 ADR（决策可逆、局限单页）。
