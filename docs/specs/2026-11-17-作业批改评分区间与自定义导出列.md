# 2026-11-17 作业批改评分区间与自定义导出列

## 1. 范围

把作业批改从「默认 0–100 分」改为**由批改页固定评分区间与自定义导出列**：

1. 配置面板新增「评分与导出设置」：最低分 / 最高分 / 及格线（默认 0/100/60），以及自定义导出列编辑器；
2. 评分区间与列定义随 `/homework/grade` 落库、随 `/chat` inputs 进入工作流，并在历史回看中恢复；
3. 内置工作流的开始 / 规划 / 人工确认 / 评分 / 汇总节点按新变量改造；
4. 逐学生结果固定为 `student / score / grade / readFiles / custom`，`custom` 承载自定义列的值；
5. 成绩卡右栏由固定的「扣分明细 + AI 评语」改为按自定义列渲染的「02 评分输出」；
6. 旧 `comment` / `deductions` 一次性迁入 `custom`，旧列保留为 legacy。

本轮**不做**：导出接口（仍为 TODO）、列拖拽排序、列表 / 对象 / 布尔类型的自定义列、按列统计。

## 2. 已确认口径

### 2.1 评分区间

- 三个数值：最低分 / 最高分 / 及格线，默认 `0 / 100 / 60`，允许一位小数，三者都可改。
- 面板表现沿用工作流抽屉的**输入变量行**：`变量名 | 变量值` 两列，三行 `score_min / score_max / pass_score`；右侧只有老师自己填的数值（类型固定 number，不显示 `num` 短码；不是选上游节点）；分节标题右侧显示当前 `min–max 分 · 及格 X`。
- 预设：`0–100 / 60`、`0–150 / 90`、`0–20 / 12`、`60–100 / 60`；点预设只填值，仍可微调。
- 校验：最低分 < 最高分，及格线 ∈ [最低分, 最高分]；前端即时提示，后端 `/homework/grade` 再次校验并返回 400。
- 落库：`homework_task.score_min / score_max / pass_score`（`NUMERIC(6,2)`），任务详情返回；历史回看回填面板。
- 开始节点声明 `score_min / score_max / pass_score`（number，可选，default 0/100/60）；规划节点必须按这组值展开 plan，不再退回 100/60；评分节点约束 `score ∈ [min,max]`；汇总节点用 `pass_score` 判 `fail_list`。

### 2.2 自定义导出列

- 面板表现沿用工作流抽屉的**输出变量行**：`变量名 | 变量类型 | 展开描述 | 删除`；类型下拉直接复用工作流变量类型树（`string / integer / number / boolean / time / object / list / file`，短码 `str / int / num / bool / time / obj / [str] / file`；`list` / `file` 带元素类型），描述在行下展开（单行输入）。
- 数量不限制，按添加顺序；预置 `deductions` / `comment` 两列（描述前缀说明中文含义），变量名可改、可删除、可调顺序（删除重建）。
- **变量名就是 key，没有 label / 默认值 / 静态列**：每一列都是逐学生输出，由模型按描述产出；变量名同时是 custom 对象键、成绩卡字段名与导出表头。
- 预置描述：扣分明细按「失分项 −扣分：依据」逐行；AI 评语先肯定优点、再指出问题与改进方向。
- 列定义通过 startnode 的 `custom_fields`（list，可选）进入工作流；显式空数组表示「本次没有自定义列」，startnode 不得用默认两列覆盖。
- 逐学生值进入固定的 `custom`（object）：输出节点契约固定为 `student / score / grade / readFiles / custom`，不再有固定的 `comment` / `deductions`。

### 2.3 工作流结构

- 开始 → 规划 → 教师确认 → 迭代（单份评分 → 输出）→ 汇总 → 结束；原「单份评语」节点合并进评分节点并删除。
- 规划节点提示词带 `score_min / score_max / pass_score / custom_fields`；评分节点一次产出 `student / score / grade / readFiles / custom`；汇总节点 `grade_sheet` 去掉 comment，只用 `pass_score` 判不及格。
- 人工确认卡片显示三个区间数值与 `custom_fields` 列表（可展开 JSON）；`custom_fields` 为可选字段，空列表不阻断确认。
- `default-flow.js` 与 `standard-grading.json` 同步；后端启动时按固定 id 对比并刷新内置工作流的 `schema_json`（软删恢复，非内置行不动）。

### 2.4 成绩卡

- 顶部学生 / 分数 / 印章 / 刻度保留；`/100` 改为 `/{score_max}`，刻度 `min → max`，失分 `max − score`，满分通过判定 `score === max`。
- 档位色以及格线为基线两等分：`< pass` 待改进；`≥ pass` 及格；`≥ pass + 50%×(max−pass)` 良好；`≥ pass + 75%×(max−pass)` 优秀。
- 右栏只保留一个 `02 评分输出`：按定义顺序渲染字段与类型短码；`string/time/file` 用衬线段落，`integer/number` 右对齐，`boolean` 显示是/否，`list` 逐项，`object` 格式化 JSON；无字段时显示空态。
- 及格线贴住区间端点（60–100、pass=max）时，把「及格」并到端点标签，避免刻度文字重叠。
- 回看时字段 / 区间使用当次任务快照，面板后续修改不影响已显示卡片。

## 3. 数据变更

### 3.1 homework_task

新增：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `score_min` | `NUMERIC(6,2) NOT NULL DEFAULT 0` | 评分区间下限 |
| `score_max` | `NUMERIC(6,2) NOT NULL DEFAULT 100` | 评分区间上限 / 满分 |
| `pass_score` | `NUMERIC(6,2) NOT NULL DEFAULT 60` | 及格线 |
| `custom_fields` | `JSONB NOT NULL DEFAULT '[]'` | 自定义导出列定义数组：`{key,description,type,schema}`；`type` 取工作流变量类型，`schema.type` 为 `list`/`file` 的元素类型 |

### 3.2 homework_grading_result

新增：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `custom` | `JSONB NOT NULL DEFAULT '{}'` | 自定义列的值：key → 文本 / 数字 |
| `comment` | `TEXT` | **LEGACY**：旧评语列，已迁移到 custom，停止写入 |
| `deductions` | `JSONB` | **LEGACY**：旧扣分明细列，已迁移到 custom，停止写入 |

### 3.3 迁移（`backend/sql/homework_score_range_custom_20261117.sql`）

- 加列、回填、设默认 / NOT NULL，可重复执行；
- **存量任务的评分区间从 description 恢复**：匹配 `(\d+)\s*[-~—–至到]\s*(\d+)`；下限 > 0 时及格线取下限（`60-100` → `60`），下限为 0 时取满分 60%（`0-200` → `120`）；
- 旧 `deductions` 列表格式化成「失分项 −N：依据」多行文本；迁移前已丢失结构的 `[object Object]` 统一替换为可读说明；
- 旧任务 `custom_fields` 回填两列预置定义，剥掉早期版本写入的已废弃 `default` 键，剥掉早期定义的 `label`（变量名即 key），并把早期的 `type=text` 归一为 `string`；旧结果 `custom` 写入 `deductions` / `comment`；
- 新环境直接由 `homework_task.sql` / `homework_grading_result.sql` 建出。

### 3.4 内置工作流同步

`WorkflowDefinitionInitializer` 每次启动读取 `standard-grading.json`，与库内固定 id（`1000000000000000001`）的 `schema_json` 对比，不同则 `upsert`；软删行恢复，表内有其它工作流也补内置行，非内置行完全不动。

## 4. 接口与契约

- `POST /homework/grade`：新增 `scoreMin` / `scoreMax` / `passScore` / `customFields`；`exportFormat` 标记 deprecated（前端不再发送）。
- `GET /homework/task/detail`：新增 `scoreMin` / `scoreMax` / `passScore`（列表项也带）与 `customFields`；`results[].custom` 返回逐学生自定义列值。
- `POST /homework/{taskId}/results`：`records[]` 用 `custom` 替代 `comment` / `deductions`；服务端按任务定义过滤未定义 key、缺失补空串。
- 开始节点 outputs：`file_tree / description / know / score_min / score_max / pass_score / custom_fields`。
- 规划节点：inputs 增加区间与列定义；plan 必须使用给定区间，维度分值之和等于 `score_max`。
- 人工确认节点：inputs / outputs 增加区间与列定义（列定义可选）。
- 迭代节点：`variableParameters` 增加区间与列定义；outputs 改为 `student / score / grade / custom / readFiles`。
- 评分节点：一次产出 `student / score / grade / custom / readFiles`，`custom` 覆盖 `custom_fields` 的每一列，并按 `type` 返回对应 JSON 类型（string/integer/number/boolean/time/object/list/file）。
- 汇总节点：inputs 去掉 comment，增加 `score_max / pass_score`；`grade_sheet` 为 `student / score / grade`。
