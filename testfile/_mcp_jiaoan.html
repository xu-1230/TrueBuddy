教学目标及支撑的毕业要求：

1、教学目标：

【1】了解SQL的基本概念与特点；

【2】熟悉 SQL Server 2012开发环境；

【3】掌握数据库的创建和使用的方法；

【4】掌握利用 SQL Server2012 进行数据库应用程序设计的方法

2、支撑的毕业要求：

使学生认识到数据库中数据操作、统计、管理技能都是为了更好的保护、管理、使用以后工作中的数据信息，懂得数据库遭到破坏后产生的不可逆转的结果;通过分析数据库破坏者的目的是什么，引导学生知法守法，遵守职业道德，理解团队协作的重要性；培养大学生理想信念、价值取向、政治信仰、社会责任。

教材解读：

《数据库原理及应用教程》第4版于2017年出版，本书版被列入案例式讲解的国家“十二五”规划数据库微课版教材，全面系统地讲述了数据库技术的基本原理和应用，内容取舍合理，重点突出，符合教学和读者的认识规律。全书共 7 章，主要内容包括：数据库系统概述、关系数据库、关系数据库标准语言 SQL、关系数据库理论、数据库安全保护、数据库设计和 SQL Server 2012 高级应用。本书除介绍数据库技术的基本原理外，还以 SQL Server 2012 为背景介绍了数据库技术的实现，包括数据库和数据表的维护、查询与统计、视图管理、存储过程和触发器的管理、用户管理、数据库的备份和还原、Transact-SQL程序设计等内容，使读者可以充分利用 SQL Server 2012 平台深刻理解数据库技术的原理，达到理论和实践的紧密结合。

教材内容循序渐进、深入浅出、概念清晰、条理性强，每一章都给出了大量的实例，并进行解释说明。同时，每章后面都附有习题，包括选择题、填空题、简答题、实验题等，从不同的角度进一步帮助读者掌握所学知识点；对重要的知识点和实践操作内容制作了相关的讲解微视频（全书共提供 38 个微课视频）、微课件，大大方便了读者的学习，读者可利用手机扫描二维码下载观看相关的内容讲解。

教学反思与持续改进（实施情况及分析）：

根据学生学习通线上视频预习点击与时长情况，课前进行数据展示，再次强调课前预习的重要性；对于无点击的学生进行课后单独谈话，了解清楚情况并加以引导。

对于上课时学生的听课以及课堂互动情况进行总结，如果是效果不理想，则及时调整教学方法，同时课后加强对学生的辅导与答疑，确保授课内容能够保质保量的吸收。

针对课后复习、课后线上线下习题完成情况，重申必须先课后复习结束后才能去完成线上线下习题。通过增加小测频次，同时强调平时成绩对于学期成绩的重要性，给予学生一定的压力；对于习题批改中发现抄袭或是缺交作业现象要加大处罚力度，引导学生独立按时完成习题。
